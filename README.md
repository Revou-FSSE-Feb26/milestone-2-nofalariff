# 🎮 RevoFun - Gaming

## 📌 Deskripsi

RevoFun adalah sebuah website landing page sederhana yang menampilkan platform game berbasis web. Website ini dirancang dengan tampilan modern dan interaktif untuk memperkenalkan beberapa mini game yang dapat dimainkan langsung oleh pengguna.

Fitur utama:

- Landing page dengan desain modern (glassmorphism + gradient animation)
- Navigasi smooth scrolling
- Section Featured Games yang menampilkan:
  - Tic Tac Toe
  - Rock Paper Scissors
  - Clicker Game
- Tombol navigasi langsung ke halaman game
- Section About sederhana
- Responsive design (mobile & desktop)

---

## 🛠️ Tech Stack

Project ini menggunakan teknologi berikut:

- HTML5 → Struktur halaman
- Tailwind CSS (CDN) → Styling dan layout
- Vanilla JavaScript → Interaktivitas (smooth scrolling)
- Google Fonts (Inter) → Typography
